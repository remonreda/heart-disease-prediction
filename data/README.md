# Data

The real dataset is **not included** in this repository.

1. Download the Framingham heart-disease dataset (e.g. search "Framingham heart disease" / "Heart Disease Prediction" on [Kaggle](https://www.kaggle.com/datasets)) — the file needs the columns listed in the main README, including the target column `Heart_ stroke`.
2. Save it as `data/heart_disease.csv`.

`sample_synthetic.csv` is **randomly generated** by `src/make_sample_data.py` with the same columns, only so the code can be run end-to-end. It contains no real patient data.
